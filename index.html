⚠ COMPLIANCE WARNING 03 · The Deciding Factor

Data Residency & HIPAA — This Is Where the Decision Is Made.

For any organization handling PHI, this is not a feature comparison. It is a contractual and regulatory boundary.

✓ Code Apps with Dataverse

  • Runs entirely inside the customer's own Azure tenant
  • Covered by a signed Microsoft Business Associate Agreement (BAA)
  • PHI, PII, and regulated workloads are explicitly supported
  • Sovereign cloud, FedRAMP, HITRUST options available
  • Data residency, audit, and eDiscovery built in

✕ Lovable on Supabase (AWS)

  • Runs on Supabase, hosted on AWS — outside the customer tenant
  • No Microsoft BAA coverage
  • Lovable's own legal documents explicitly prohibit PHI
  • Cannot be easily relocated into a customer Azure subscription

Direct quotes from Lovable's own legal documents

These are not interpretations. They are verbatim from Lovable's published policies — and they are unambiguous.

Terms & Conditions lovable.dev/terms

"You agree not to upload, input, or otherwise provide any protected health information under HIPAA, or any other sensitive categories of data… Our Services are not designed to handle that type of data, and we disclaim all responsibility if you choose to submit it."

Data Processing Agreement · Section 8 lovable.dev/data-processing-agreement

"The Customer shall not provide any data to Lovable which is classified as sensitive. For the avoidance of doubt, the Customer agrees not to upload… any protected health information under HIPAA…"

Privacy Policy lovable.dev/privacy

Explicitly warns against uploading sensitive health data.

Microsoft's Key Takeaway for Healthcare & Life Sciences

Microsoft signs a BAA and keeps all data inside your own Azure tenant. Lovable does not. This is written directly in their own legal documents — linked above. For any organization handling PHI, this single fact ends the conversation.

04 · Agentic AI

The MCP Server Advantage

In the era of intelligent agents, the data layer must speak the agent's language. Dataverse ships a native Model Context Protocol (MCP) Server. Azure SQL does not.

Dataverse

One Connection. Total Context.

  • Agents auto-discover tables, columns, relationships
  • Row-level & column-level security flow through automatically
  • Business rules and choice sets are introspectable
  • Copilot Studio, M365 Copilot, and custom agents all benefit
Azure SQL

Plumbing Without Meaning

  • No native MCP layer — every agent integration is bespoke
  • Schema, joins, and security must be hand-described to each agent
  • Drift between schema and agent prompts is constant maintenance
  • Each new agent restarts the integration cost

Lovable — Opaque Models, Hidden Capability

  • No model transparency — you don't know which model, or which version, is generating your app
  • Cannot verify whether you're on the latest frontier capability or a year-old release
  • Lovable decides the model roster — switching is not the customer's decision
  • No version history, no audit trail of which model produced which artifact
  • Enterprise key management and routing lives outside customer control
  • In a landscape where leadership shifts weekly, opacity is a strategic liability
Why transparency matters: coding model quality is improving on a near-monthly cadence — Claude, GPT, and Gemini have each held the top of the SWE-bench style leaderboards at different points. If you can't name the model, you can't verify you're using the best one. With Code Apps, you always can.

09 · Strategic Conclusion

For governed, compliant, agent-ready scale — Code Apps with Dataverse is the clear winner.

Choose Code Apps when you value:

  • Tenant-resident, BAA-covered data (PHI, PII, regulated)
  • A maturity model from citizen to pro developer
  • Native MCP and agent intelligence
  • Configure-once governance for 1,000+ makers
  • External-facing apps via Power Pages BYOC
  • Freedom to use any frontier AI model in VS Code

Reconsider Lovable when:

  • PHI or other regulated data is in scope
  • You need tenant-wide governance and ALM
  • Hundreds of repos and Supabase instances are unmanageable
  • Agent integration is a strategic priority
  • Long-term maintainability matters more than first-week velocity

"The AI coding tool is just the hammer. The platform is the house."

For organizations that value governance, compliance, agent integration, long-term maintainability, and the ability to scale citizen development safely — especially when PHI is involved — Power Platform Code Apps with Dataverse is the clear, defensible enterprise choice.
